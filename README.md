# AI Resume Analyzer (GenAI + Streamlit)

A GenAI-powered Resume Analyzer built using Streamlit and Groq LLMs.

## 🚀 Features
- Upload PDF or Word resumes
- AI-generated resume summary
- Skill extraction
- ATS-style scoring
- Improvement suggestions
- Visual score charts

## 🛠 Tech Stack
- Python
- Streamlit
- Groq LLM
- Pandas
- PyPDF2 / python-docx

## ⚙️ Setup

```bash
git clone https://github.com/your-username/gen_ai_resume_analyzer.git
cd gen_ai_resume_analyzer
python -m venv venv
venv\Scripts\activate
